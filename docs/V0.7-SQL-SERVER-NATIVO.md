# Agencia EH V0.7.1 — SQL Server nativo

## Arquitectura vigente
- Frontend: Next.js 14, React 18 y TypeScript.
- API: Node.js + NestJS.
- Base de datos: Microsoft SQL Server.
- Acceso a datos: paquete `mssql` con consultas parametrizadas; no se utiliza ORM.
- Sesiones: JWT de acceso y refresh token en cookie HttpOnly.

## Configuración
1. Ejecuta `backend/database/00-create-database.sql` en SSMS.
2. Selecciona `AgenciaEH` y ejecuta `backend/database/01-schema.sql`.
3. Copia `backend/.env.example` a `backend/.env` y configura credenciales.
4. Ejecuta `npm install`, `npm run db:check`, `npm run build` y `npm run start:dev` en backend.
5. En frontend, configura `NEXT_PUBLIC_API_URL`, instala dependencias y ejecuta `npm run dev`.

## Alcance incluido
- Conexión SQL Server centralizada y pool de conexiones.
- Registro, inicio/cierre de sesión, renovación de sesión y perfil.
- Verificación de correo y recuperación de contraseña con enlaces de desarrollo en consola.
- Gestión de propiedades, revisión administrativa y catálogo público paginado.
- Esquema SQL inicial con usuarios, perfiles, propiedades, imágenes, leads y favoritos.

## Validación pendiente
No se ha ejecutado compilación ni prueba de integración contra una instancia SQL Server real en este entorno. Antes de producción, ejecutar pruebas de build, conexión, autenticación, autorización, CRUD y moderación; configurar proveedor de correo, HTTPS, secretos y límites de peticiones.
